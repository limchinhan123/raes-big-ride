# Rae's Big Ride v1.0.0

Released 2026-08-12.

This is the first documented open-source release of Rae's Big Ride. The package
was already versioned `1.0.0`; earlier development was not accompanied by
release notes or version tags.

## Highlights

- A browser-based, voice-guided 3D ride through six Singapore-inspired scenes,
  with touch, keyboard, and grown-up current-card fallbacks.
- A procedural runtime world, textures, music, and sound effects, alongside
  documented provenance for committed screenshots and gameplay media.
- MIT licensing, package metadata, third-party notices, and a contributor
  workflow with privacy, media, and accessibility expectations.
- A configurable speech-matching boundary, deterministic unit tests, and CI
  checks for the test suite and production build.
- Clearer unsupported-browser and microphone-failure states, including a
  grown-up fallback for the active card.
- Privacy and security documentation that distinguishes app behavior from
  browser speech-provider and hosting boundaries.
- A source-backed repository landing page, changelog, reproducible release
  checklist, and private GitHub vulnerability-reporting route.

## Verification

At this release point, the repository's CI is configured to run `npm ci`,
`npm test`, and `npm run build` for pull requests and pushes to `main`. The
current test suite contains 42 unit tests. No coverage percentage is claimed.

## Real-device speech limitation

The game uses browser Web Speech recognition with `en-SG`. Automated tests and
CI cannot prove real-device browser support, microphone permission outcomes,
speech-provider availability, network behavior, room acoustics, or hardware
quality. A guardian should supervise microphone use, and the touch, keyboard,
and grown-up-assist fallbacks remain important when voice input is unavailable.
