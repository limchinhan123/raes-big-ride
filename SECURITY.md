# Security Policy

## Report a vulnerability privately

Do not report security vulnerabilities in public GitHub issues. Use this
repository's GitHub Private Vulnerability Reporting flow from the **Security**
tab instead.

Do not include a child's personal data, microphone recordings, transcripts,
credentials, or other sensitive information in a report.

Please include a clear description, affected URL or code path, reproducible
steps or a minimal proof of concept, and the likely impact.

## Scope and expectations

Relevant areas include the client-side app, dependencies, deployment
configuration, browser permissions, cross-site scripting, and unintended
handling of microphone or child-related data.

Please avoid accessing other users' data, using real child data, disrupting
the service, or performing denial-of-service testing. Reports will be assessed
and, where appropriate, fixed and disclosed in coordination with the reporter.
This project makes no service-level response-time commitment and offers no
bounty.

## Supported version

Only the current `main` branch and the currently deployed version are
supported.
